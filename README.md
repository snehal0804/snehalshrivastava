# Power Platform Developer Portfolio

This is a personal portfolio website for a Power Platform developer.

## Features

- About section
- Skills in Power Platform tools
- Projects showcase
- Contact information

## How to View

Open `index.html` in your web browser.

## Customization

Edit the content in `index.html` to personalize with your information.
Update `style.css` for styling changes.
Modify `script.js` for additional interactivity.
